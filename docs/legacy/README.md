# 历史文档归档

本目录保存 Pi 主产品形成前后的设计、讨论和方案证据。它们用于理解决策演进，不是当前运行入口；当前实现以 [`pi-agent/`](../../pi-agent/) 的源码、测试和文档为准。

| 目录 | 内容 |
|---|---|
| [`design/`](design/) | 鞍钢方案版本、架构分析、Cline 改造方案和角色设计。 |
| [`guides/`](guides/) | 早期快速上手与模型、API 配置说明。 |
| [`discussions/`](discussions/) | 早期讨论记录、回测报告和测试题目。 |
| [`solutions/`](solutions/) | 历史 `ansteel-solution-*.md` 讨论结果。 |

根目录的兼容脚本仍可运行，但新的旧脚本产物会写入 `artifacts/runtime/`，不再写回项目根目录。
