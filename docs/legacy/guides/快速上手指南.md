# 🚀 鞍钢宪法式AI防幻觉讨论 — 快速上手指南

> 5分钟开始你的第一次防幻觉讨论

---

## 第一步：配置 Kilo Code API（只需做一次）

1. 打开 VS Code
2. 点击左侧 Kilo Code 图标（或按 Ctrl+Shift+P 搜索 "Kilo Code"）
3. 点击 ⚙️ 设置 → **API Configuration**
4. 选择 Provider：**Anthropic**（或 OpenAI Compatible）
5. 填入：
   - **API Key**: 你的Key
   - **Base URL**: https://ne.60002.cn （如果用代理）
   - **Model**: claude-sonnet-4-20250514（或其他可用模型）
6. 点击 Save

> 💡 如果你想给三个角色配不同的API：
> 在 API Configuration 中添加多个 Provider 配置，
> 然后在每个 Agent 的 .md 文件中修改 model 字段。

---

## 第二步：打开项目

1. 在 VS Code 中打开文件夹：`F:\codex\ai群讨论`
2. Kilo Code 会自动识别：
   - `.kilo/agents/` 下的 4 个自定义 Agent
   - `.kilo/rules/` 下的鞍钢宪法规则
   - `AGENTS.md` 项目级指令

---

## 第三步：开始讨论（两种方式）

### 方式A：手动切换Agent（推荐新手）

在 Kilo Code 聊天面板中：

**步骤1** — 点击Agent选择器 → 选 `tech-lead` → 输入：
```
请立项：[你的问题，比如"React 19的use() hook能否在条件语句中使用？"]
```

**步骤2** — 切换到 `staff-engineer` → 输入：
```
请针对以上立项提出完整方案，每个事实性断言标注L1-L4置信度。
```

**步骤3** — 切换到 `qa-engineer` → 输入：
```
请逐条审查以上方案，行使质疑权和否决权。
```

**步骤4**（如QA否决）— 切回 `staff-engineer` → 输入：
```
请逐条回应QA的质疑，修正方案。
```

**步骤5** — 切回 `tech-lead` → 输入：
```
请亲自验证关键断言（干部参加劳动），用搜索/执行代码等方式验证。
```

**步骤6** — 依次让三个Agent Sign-off：
```
请对最终方案进行Sign-off（同意/反对+理由）。
```

**步骤7** — 让 tech-lead 归档：
```
请汇总讨论记录，输出最终结论（带置信度标注），保存为Markdown文件。
```

### 方式B：用协调器（更自动化）

选择 `ansteel-orchestrator` Agent → 输入：
```
请按照鞍钢宪法七步流程讨论以下问题：[你的问题]
```
协调器会自动依次调用三个Agent完成七步流程。

---

## 第四步：查看结果

讨论完成后，最终结论会保存为 Markdown 文件，包含：
- 最终结论 + 置信度标注
- 完整讨论记录（七步全部留痕）
- 三方Sign-off记录

## 常见问题

**Q：Agent选择器在哪里？**
A：Kilo Code 聊天面板顶部，显示当前Agent名称的下拉菜单。

**Q：怎么切换Agent？**
A：点击Agent名称 → 从列表中选择。自定义Agent会显示在列表中。

**Q：QA一直否决怎么办？**
A：最多修正3轮。如果3轮后仍未通过，你（用户）介入裁决。

**Q：能不能用中文讨论？**
A：可以。Agent会自动用你输入的语言回复。

**Q：怎么扩展团队？**
A：在 `.kilo/agents/` 下添加新的 .md 文件即可。参考V6文档第3.10节。
