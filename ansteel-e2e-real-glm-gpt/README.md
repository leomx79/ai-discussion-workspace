# Insertion Index Review Fixture

`insertionIndex(sorted, target)` must return the first insertion position in a sorted ascending array.

Required boundary behavior:

- `insertionIndex([], 8) === 0`
- `insertionIndex([1, 3, 5], 0) === 0`
- `insertionIndex([1, 3, 5], 3) === 1`
- `insertionIndex([1, 3, 5], 8) === 3`
